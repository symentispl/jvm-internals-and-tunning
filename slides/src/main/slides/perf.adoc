== Writing performant Java applications

=== Agenda

* Method: find the bottleneck before you fix anything
* *CPU bound*: JIT, algorithms, data layout
* *Contention bound*: Amdahl, scalability law, concurrency models, lock-free
* *I/O bound*: effective I/O, serialization
* *Memory bound*: allocate less, native memory, GC tuning
* Summary: symptom, tool, fix
