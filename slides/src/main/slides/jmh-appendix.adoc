== Appendix: JMH cheat sheet

Everything above is how benchmarking works. This appendix is the command reference.

=== Command line

[cols="1,3",options="header"]
|===
|Option |Meaning
|`-f 3` |forks
|`-wi 5 -w 1s` |warm-up iterations and their time
|`-i 5 -r 1s` |measurement iterations and their time
|`-t 4` |threads
|`-p name=a,b` |override `@Param` values
|===

=== Command line, more

[cols="1,3",options="header"]
|===
|Option |Meaning
|`-bm avgt` |mode: `thrpt`, `avgt`, `sample`, `ss`
|`-tu ns` |time unit
|`-prof <name>` |profiler (`-lprof` lists them)
|`-rf json -rff out.json` |result format and file
|`-l`, `-lp` |list benchmarks, list parameters
|===

=== Useful annotations

[cols="1,3",options="header"]
|===
|Annotation |Use
|`@Fork(value = 3, jvmArgs = "-Xmx2g")` |forks and JVM options per benchmark
|`@Warmup`, `@Measurement` |iterations and time
|`@BenchmarkMode`, `@OutputTimeUnit` |mode and unit
|`@CompilerControl(DONT_INLINE)` |keep a method out of inlining (benchmark helpers)
|`@OperationsPerInvocation(n)` |the benchmark body does n operations
|===

=== Profiler setup

 sudo sysctl kernel.perf_event_paranoid=-1      # perf, async-profiler
 sudo sysctl kernel.kptr_restrict=0
 export ASYNC_PROFILER_DIR=/path/to/async-profiler

 java -jar benchmarks.jar -prof "async:libPath=$ASYNC_PROFILER_DIR/lib/libasyncProfiler.so;output=flamegraph"
 java -jar benchmarks.jar -prof perfasm         # needs hsdis and perf
